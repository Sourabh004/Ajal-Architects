( Process )

How a project moves

  1. 01 — 2–3 weeks

    Listen

    Site visit, survey and a long conversation about how you live or work. We study sun, wind, views and the bylaws before we draw.

  2. 02 — 4–6 weeks

    Concept

    Plans, massing models and a first set of 3D views. Two or three clear options, each with an honest cost range.

  3. 03 — 8–12 weeks

    Develop

    Structure, services, materials and every junction resolved. Approval drawings, tender set and photoreal renders.

  4. 04 — on site

    Build

    Weekly site visits, contractor coordination and a snag list we close before handover. Whoever drew it, sees it built.

( Principles )

Five things we won't compromise

  1. 01

    Climate first, form second

    Comfort should come from the building, not the air-conditioner.

  2. 02

    Material honesty

    Concrete reads as concrete, brick as brick, timber as timber. Nothing pretends.

  3. 03

    The plan is the argument

    If it doesn't work in plan, no rendering will save it.

  4. 04

    Detail at 1:1

    The quality of a building lives in the twenty millimetres nobody photographs.

  5. 05

    Build for the second owner

    Spaces that can change use without demolition. Longevity is sustainability.

( Story )

Eleven years, one obsession

2014

Two drawing boards

The studio opens in a converted garage in Jayanagar with a single commission — a small house for a retired schoolteacher.

2017

First public building

A community library puts the studio's low-carbon detailing in front of a wider audience.

2020

The material library

Every finish we specify gets catalogued — supplier, embodied carbon, how it ages. It now runs to 400+ entries.

2023

A studio of fourteen

Design, technical and site teams — still around one drawing table.

2025

Beyond the city

Work extends into Kerala and coastal Karnataka, testing the studio's language against humidity and salt.
